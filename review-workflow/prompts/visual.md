# Art direction and visual system

Review typography, optical hierarchy, spacing rhythm, responsive composition,
color relationships, balance, shape language, icons, marks, component states and
cross-product distinctiveness. Look for conflicts between written rules and
actual rendered examples. Use provided desktop and mobile images as evidence.

Source inspection alone cannot establish rendered quality. If rendered images
are missing, stale, unreadable, or do not cover the reviewed areas, set
complete=false and say exactly what remains unverified. Distinguish the visual
intent from its implementation; do not flatten intentional differences into
uniformity. PI must visibly use a bold pi mark, with useful minimum-size,
clear-space and monochrome guidance.

Check legibility of small labels, card padding, line lengths, heading wraps,
alignment of grids, table overflow, narrow screens and the optional print view.
